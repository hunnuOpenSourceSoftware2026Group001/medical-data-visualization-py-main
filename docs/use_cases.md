# 需求分析与用例说明

## 1. 系统概述
面向医疗机构的「疾病数据可视化与智能分析系统」，为医生、数据分析师与管理者提供：
病例管理、数据可视化大屏、疾病预测、报告生成、AI 医疗咨询五大能力。

## 2. 参与者（Actors）
| 参与者 | 说明 |
|---|---|
| 医生 / 医务人员 | 查询、录入、维护患者病例，使用疾病预测与 AI 咨询 |
| 数据分析师 | 查看可视化大屏、导出数据、生成分析报告 |
| 系统管理员 | 维护数据源、导入导出病例、管理报告模板 |
| DeepSeek 大模型 | AI 咨询的外部支撑（参与者） |

## 3. 用例清单
| 编号 | 用例 | 参与者 | 对应功能模块 |
|---|---|---|---|
| UC1 | 患者病例管理 | 医生/管理员 | cases CRUD/导入导出 |
| UC2 | 数据可视化大屏 | 分析师/医生 | statistics dashboard |
| UC3 | 疾病预测 | 医生 | prediction |
| UC4 | 报告生成 | 分析师 | reports + templates |
| UC5 | AI 医疗咨询 | 医生/患者 | consultation |
| UC6 | 数据导入导出 | 管理员 | cases import/export |

## 4. 详细用例

### UC1 患者病例管理
- **前置条件**：系统已启动，数据库已初始化。
- **触发**：医生进入「数据管理」页面，或通过接口访问 `/cases`。
- **基本流程**：
  1. 系统分页展示病例列表（可按关键词、疾病类型、科室、性别筛选）。
  2. 医生可新增病例，填写疾病类型、性别、年龄、病情描述等。
  3. 系统校验必填项（疾病类型、病情描述），保存并返回完整病例。
  4. 医生可编辑或删除指定病例。
- **备选/异常流程**：
  - 3a. 必填字段为空 → 系统返回 `400 参数错误`。
  - 4a. 病例不存在 → 返回 `404 资源不存在`。
- **后置条件**：病例数据被持久化/更新/删除，列表同步刷新。

### UC2 数据可视化大屏
- **前置条件**：库中存在病例数据。
- **基本流程**：
  1. 进入首页大屏，前端调用 `/statistics/dashboard`。
  2. 系统统计：病例总数、疾病类型分布（饼图）、科室分布（柱状图）、性别比例、年龄段分布、症状词云、最新病例。
  3. 前端渲染图表。
- **异常流程**：无数据时返回空数组结构，前端展示“暂无数据”。

### UC3 疾病预测
- **前置条件**：已完成模型训练数据准备（来自历史病例）。
- **基本流程**：
  1. 医生输入病情描述，调用 `/prediction/predict`。
  2. 系统基于 TF-IDF + 朴素贝叶斯对文本分类，输出疾病类型、置信度、健康建议，以及相似历史病例 Top3。
  3. 前端展示结果并提示“仅供参考，不能替代医生诊断”。
- **异常流程**：描述为空 → `400 参数错误`；模型数据不足 → 返回“未知/建议就医”。

### UC4 报告生成
- **前置条件**：存在病例数据与报告模板。
- **基本流程**：
  1. 分析师选择报告模板并设置筛选条件，调用 `/reports/generate`。
  2. 系统生成关键指标（平均/最大/最小年龄）与各章节内容。
  3. 分析师可导出 Word 报告（`/reports/export`）。
- **备选流程**：管理员可对模板进行创建、发布、下线、删除（`/templates`）。
- **异常流程**：模板不存在 → `404`。

### UC5 AI 医疗咨询
- **基本流程**：
  1. 用户输入问题，调用 `/consultation/chat`。
  2. 系统优先调用 DeepSeek 大模型；未配置密钥时使用规则兜底回答。
  3. 返回答案与免责声明。
- **异常流程**：内容为空 → `400`；大模型异常 → 自动降级为规则回答。

### UC6 数据导入导出
- **基本流程**：
  1. 导出：管理员下载病例 CSV（`/cases/export`）。
  2. 导入：上传 CSV（`/cases/import`），系统校验必需列后批量入库，返回成功/失败数量。
- **异常流程**：缺少必需列 → `400 导入文件缺少必需列`。

## 5. 非功能需求
- **统一响应**：所有接口返回 `{code, message, data, timestamp}`。
- **统一异常**：业务异常、HTTP 异常、未知异常均在全局处理器中转换为统一结构。
- **可移植**：默认 SQLite 零配置运行，可通过环境变量切换 MySQL。
- **可测试**：分层清晰，服务层与仓储可独立单测。
